HookCallback

class HookCallback(source)

Backend-neutral method-hook callback builder.

Both legacy Xposed and libXposed execute before before the original invocation and after afterwards. Setting HookParam.result in before skips the original invocation; calling HookParam.throwThrowable makes it throw instead.
